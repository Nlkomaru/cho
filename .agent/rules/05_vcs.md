# Version Control

- リポジトリは [Cho](https://github.com/Nlkomaru/cho) です。
- ブランチを作成する場合は、実際のリモートの既定ブランチを確認してから作成し、PR の base もそのブランチにします。
- merge はユーザーの明示的な依頼を受けてから行います。branch、commit、push、Issue、Pull Request の作成もユーザーから依頼された場合だけ実行します。
- ユーザーの作業中の変更を revert、reset、checkout、強制 push しません。
- 秘密情報、ローカルデータ、`.dev.vars`、生成済み認証情報をコミットしません。
- 永続データのスキーマを変更する場合は、手作業だけにせず再現可能な migration としてコミットします。
- コミットメッセージは変更内容を端的に表す英語の命令形にします。
- リモートと既定ブランチは操作前に実際の Git 設定から確認し、存在を仮定しません。
